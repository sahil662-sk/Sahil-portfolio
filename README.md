# 🌐 Sahil's Personal Portfolio Website

A modern, responsive, and feature-rich personal portfolio web application designed to showcase my projects, technical toolkit, work experience, and educational background. Hosted on Vercel with high-performance global CDN delivery.

🔗 **Live Demo:** [sahil-portfolio-three-eosin.vercel.app](https://sahil-portfolio-three-eosin.vercel.app/)

---

## ✨ Features

- 📱 **Fully Responsive Layout:** Optimized for seamless viewing across mobile devices, tablets, and desktop computers.
- 🚀 **Featured Projects Showcase:** Highlights full-stack applications, interactive web tools, and state management apps with live links and source code access.
- 🛠️ **Interactive Technical Toolkit:** Clean visual layout detailing core programming languages, frameworks, databases, and developer tools.
- 💼 **Professional Experience Timeline:** Displays professional engineering, quantitative research, and technical roles.
- 🎓 **Academic Background:** Overview of educational degrees, technical coursework, and academic milestones.
- 📬 **Direct Contact Section:** Quick links to professional profiles like LinkedIn, GitHub, and X (Twitter).

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript / React / Next.js
- **Styling:** Tailwind CSS / Modern CSS Modules
- **Deployment & Hosting:** [Vercel](https://vercel.com/)

## 🚀 Getting Started Locally

To set up and run a local copy of this portfolio on your machine, follow these simple steps:

### 1. Prerequisites
Ensure you have **Node.js** and **npm** (or **yarn**) installed on your system.
- [Download Node.js](https://nodejs.org/)

### 2. Clone the Repository
```bash
git clone [https://github.com/sahil662-sk/sahil-portfolio.git](https://github.com/sahil662-sk/sahil-portfolio.git)
cd sahil-portfolio
. Install Dependencies
Bash
npm install
# or
yarn install
4. Run the Development Server
Bash
npm run dev
# or
yarn dev
Open http://localhost:3000 (or the port specified in your terminal) in your browser to view the portfolio locally!

📦 Deployment
This repository is configured for automated continuous deployment via Vercel:
